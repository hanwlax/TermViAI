# TermViAI 现代界面与交互（2026-09-17）

本轮参考用户提供的 17.9 秒 Termius 录屏，继续使用原生 GPU 界面。录屏中的窗口内容仅作为视觉及操作参考，没有执行录屏内的命令、导入其中的主机或发起 SSH 连接。

## 界面变化

- 使用统一的 24 单位矢量路径绘制菜单、Hosts、Keychain、终端、搜索、增删、窗口控制、分屏和广播成员等图标；常用图标显示为 18 逻辑像素，不再依赖特殊字符字体。
- 深紫灰色背景、柔和紫色强调色、统一圆角和按钮内边距。文字、图标、点击区域独立布局；Tab 标题预留关闭按钮空间，搜索框预留 Connect 空间，窄窗口隐藏次要工具栏项。
- 主机和分组卡片的标题、说明使用透明底色，悬停效果连续；细滚动条圆角受宽度约束；最大化后切换恢复图标。
- 图标按钮与广播控制有延迟提示，按钮按下有即时反馈，指针离开侧栏后清除高亮。

## 动画

| 操作 | 原生过渡 |
| --- | --- |
| 打开 Add/Edit Host、Add Key | 220ms 右侧滑入，背景遮罩渐入 |
| 外部点击、Cancel、Escape、保存成功 | 180ms 滑出，保留退场图形并阻断重复提交及点击穿透 |
| 按钮悬停 | 120ms 颜色过渡 |
| Hosts / Keychain 内容切换 | 160ms 淡入与 8px 位移 |
| 分屏落点出现 | 100ms 半透明绿色预览 |

动画根据实际时间推进，反向操作从当前进度继续，刷新频率最高 60fps 且受窗口 `max_fps` 约束。动画结束后停止请求动画帧；不增加空闲轮询。抽屉的绘制、点击、滚轮和 IME 坐标使用相同位移，滑出窗口时由 GPU 视口裁剪。

## 将现有会话放入同一 Tab

1. 先切换到作为目标的终端工作区。
2. 按住另一个只有一个终端窗格的 Tab，将其拖进当前终端区域。
3. 靠近目标窗格的左、右、上、下边缘会显示对应的半窗格预览。
4. 松开后移动已有会话，不重新连接。移动后可继续使用当前 Tab 的广播开关与成员复选框。

移动距离不足 6 个逻辑像素仍按普通 Tab 点击处理。Esc、失焦、区域外松手会取消。多窗格源 Tab 不整体合并；缩放中的目标窗格需先恢复。关闭、已移动、失联、过小或正显示 overlay 的会话不会被作为落点。

原有同 Tab 新增 SSH 分屏、All/None 与逐窗格独立输入仍保留，见 [广播说明](BROADCAST.md)。本轮未增加 SFTP、Vaults、账号管理、Telnet 或先前排除的侧栏入口。

## 设计预览与真实应用

[交互式设计预览](modern-ui-preview.html) 是离线 HTML 设计说明，图标路径直接来自 Rust 矢量定义，明确标注示例数据。可用于查看配色、间距和过渡方向；它不是原生窗口截图，也不能用来证明 Windows 运行验收通过。预览里的示例列表切换等辅助控件不代表全部已加入原生产品。

原生实现主要位于 `termviai_ui.rs`；矢量路径、时间插值、落点几何、会话拖放分别位于 `termviai_icons.rs`、`termviai_motion.rs`、`termviai_dock.rs`、`termviai_tab_drag.rs`。最终构建和测试证据见 [本轮验证记录](MODERN_UI_VALIDATION.md)。
